The assistant can advise you—or act when you ask

A question stays conversational. A clear instruction creates a preview of the requested change.

Ask for advice

Ask whether a job is worth applying for, what to emphasize, how to explain a gap, or what to expect in an interview.

Ask it to do something

Tell it to tailor the resume, change the design or font, adjust spacing, manage the scan code, or restore template formatting.

Example“Use a navy Sidebar, tighten the spacing, and make the scan code open my LinkedIn profile.”
Chat is its own floating window. Choose the round Chat launcher to open it. Drag the header to move it, drag the lower-right corner to resize it, use — to collapse it, and choose the launcher again to return to the same conversation. Its position, size, open state, and bounded chat history survive a refresh in this browser. On a phone, chat automatically uses the safe full-width layout.
If a reply arrives while chat is collapsed, the red badge on the launcher shows how many messages are waiting. Opening chat clears the badge after the messages are visible.
The assistant will not invent experience, silently change owner-controlled settings, or claim a change was saved when it was not.

What “approval needed” means

Application tailoring may reword and emphasize facts already approved in My resume. It may not add a new title, employer, date, credential, competency, accomplishment, or Highlight from a job posting or attached file. This does not mean you do not have that experience; it means Resume Studio does not yet have your approval to present it as a fact.

How to approve a new fact

Open Edit my resume, add or support the fact, choose Save to my resume, then retry your chat request. Studio names each item it left out. If Studio itself changes a protected detail or page-placement flag, it restores the approved value automatically and still applies the supported parts.

If an update cannot be repaired safely: Studio leaves the resume unchanged and asks you to retry. The explanation describes the customer action to take; it does not show internal paths such as experience array numbers.

Attach files or a whole folder

Open Attach files or a folder above the message box. Choose up to 20 PDFs (including scanned PDFs), Word, Excel, PowerPoint, text or code files, photos, or screenshots—or choose a folder and let chat review its readable files together. You can also drag files or a folder into the attachment area.

Private, bounded, and removable

Each file can be up to 10 MB and each batch up to 30 MB. Folder names are kept so chat understands the context. Originals are read, never executed; attachments are private to Resume Studio and are removed after seven days or immediately when you choose Remove.

Example“Review everything in this application folder together. Tell me what is missing, what conflicts, and what decision you need from me.”

5

“Keep” and “Save” do two different jobs

This is the most important distinction in the Studio.

After chat formatting

Choose Keep these changes

The pinned approval bar stays above the message box. Keep preserves the preview through reloads and uses it for the PDF.

OR
After permanent resume edits

Choose Save to my resume

This commits the reviewed text and formatting changes to your permanent master resume.

Text edits autosave as a browser draft while you type. While editing, use the + Add control beside Professional Summary, Core Competencies, Selected Accomplishments, or a job to create a new item directly where it belongs on the resume, then type into the new row. Clicking elsewhere or choosing Done editing keeps the new wording in the preview and its saved draft; every title, name, and contact-detail change is kept too. To remove a Highlight, erase all of its text on the page or use the × button in the list below; the item stays removed through save, reopen, and PDF. “Saved to your resume” means the permanent version is committed. If pasted text brings foreign formatting, choose Restore template formatting; use Core Competencies spacing for intentional gaps between competency items.
6

Named resume versions open across your devices

Your permanent master stays separate. Choose which named working version should open everywhere.

Name it

Open Your resume versions

Enter a clear name such as General, Real Estate, or a company and role. When protecting a browser source, use a new distinctive name and choose Save as a new version so no prior version is overwritten.

Share it

Choose Save across devices

The exact wording, design, job context, photo, photo crop, and rendering choices on this screen become one named version. If the visible browser copy contains deliberate owner edits that differ from the current shared record—including direct edits to a tailored version or an untailored MASTER—review the visible resume and complete the separate confirmation step; nothing is stored before that second confirmation.

Choose it

Use everywhere

The version marked Active everywhere opens automatically after you enter your passcode on any authorized device. If that browser still has an older draft with no shared-version record, Studio opens the active version first and keeps the older draft on that device for recovery.

Every save is recoverable

Each save creates a new revision. Open History to compare, open, or restore an earlier revision without deleting the current one. The latest 25 revisions remain available; older revisions are removed automatically after that limit.

You stay in control of conflicts

If a named browser version and the shared version differ, Studio shows both timestamps and asks which one should open everywhere. Whichever one you do not choose is preserved as a separate named version first. An older browser-only draft is instead kept on that device with a Review older browser draft control while the active shared version opens.

You can rename, duplicate, open, review history, and activate saved versions. A custom photo and its zoom/position travel together inside the authenticated version and are restored for PDF export; the photo is not placed on a public URL. If “Review changes before updating MASTER” appears, check “Changes in this save,” then choose “Update MASTER” only when those are the changes you want. That list compares this browser copy with the current saved MASTER version, so earlier differences from the permanent resume source are not presented as part of the new save. If Studio stops a save, your edits remain visible, and choosing another version opens the same review step so you can confirm or cancel before anything switches. Temporary connection failures still retry. Updating a named version does not change or delete the permanent resume source.

Your saved applications keep their editable state

Sign out, return later, and reopen the exact resume version you saved.

What is preserved

  • Template, colour, font, spacing, dividers, and scan-code choices
  • The tailored text and approved edits
  • The editable data used for PDF export

Where to find it

Open Resume tools, then Your applications. Select an editable version to reopen it.

Older PDF-only files are labeled Unavailable instead of opening a broken editor.

9

Report a problem or request a feature inside chat

The Studio creates a real ticket, alerts support, and shows its number only after both succeed. Support then owns it through a verified outcome.

Example“Please report that pasted text changed the font, and show me the ticket number.”

A real ticket is created

You will see the ticket number and a clickable link in the conversation.

Support owns the ticket

Support is alerted immediately and sends one received/working acknowledgement. After that, this chat shows only a necessary question or a verified completion/private-preview note. A five-minute safety check catches a missed alert without creating duplicates. If either step fails, the Studio says so and does not claim success.

10

Review a protected support preview and decide whether to keep it

A support preview is a separate copy. It only becomes your saved resume if you choose to keep it.

Open

Use the link from Studio chat

The private link contains only a random review ID. Enter the same Resume Studio passcode to see the copy.

Review

Check the page and PDF

Confirm the requested placement, photo crop, page flow, and the downloadable preview PDF.

Decide

Keep this version, or ask for changes

If it is right, press Keep this version on the preview and confirm. That saves exactly what you reviewed as a new version in Resume Studio. If it is not right, report the exact changes you want inside Studio chat.

Opening or downloading a protected preview changes nothing. Your saved resume changes only when you press Keep this version and confirm, and then it saves exactly the copy you reviewed as a new version with your earlier versions still in history. Keeping works once, and it is refused if your saved resume changed after this review copy was made, so nothing you saved in the meantime can be quietly undone.
